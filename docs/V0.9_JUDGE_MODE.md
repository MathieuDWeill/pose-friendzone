# POSE × Vouch v0.9 — Single-instance Judge Mode

`JUDGE_MODE = true` is intentionally test-only.

With exactly one real avatar:
1. A visible cyan hologram occupies one of two formation targets.
2. The judge must physically occupy the other target.
3. Holding the completed pose triggers the success burst.
4. Vouch Test moves the hologram near center.
5. Standing beside it validates the Vouch interaction.
6. The full loop is therefore testable in one Explorer instance.

## Before final production release
Set:
```ts
const JUDGE_MODE = false
```

Real multiplayer logic remains unchanged.
