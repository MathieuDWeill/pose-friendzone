# Vouch integration

A generic like is cheap. A Vouch should follow evidence.

POSE supplies that evidence: players have just coordinated under time pressure. Only after a successful formation does the Vouch Round appear.

## Flow
1. Solve a POSE formation with 2–8 humans.
2. `WHO DO YOU VOUCH FOR?` appears for five seconds.
3. Stand within 2.1m of the teammate you would choose again.
4. Each avatar can vouch for at most one teammate: its nearest eligible teammate.
5. Session totals appear in the HUD.

## Competition-build limits
- Session-local only
- No negative rating
- No token/NFT
- No wallet transaction
- No external database
- No paid API
- No permanent public reputation score
