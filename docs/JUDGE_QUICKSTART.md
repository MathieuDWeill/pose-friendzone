# Judge Quickstart

POSE is intentionally designed to be understood without reading documentation.

## 30-second test

1. Enter the scene.
2. If you are alone, walk onto the glowing center pad. This is rehearsal mode.
3. Bring/open a second player in the same scene.
4. Wait for the short synchronized countdown.
5. Move one avatar onto each glowing pad.
6. When every pad is occupied correctly, all pads turn green.
7. Hold the formation for about one second.
8. The scene displays **PERFECT!** and automatically advances to another pose.

## What to evaluate

- **Mobile-first:** gameplay requires movement only.
- **Social value:** the actual solution is distributed across human bodies/avatars.
- **Accessibility:** almost no reading or nested interface is required.
- **Performance:** the scene is primitives and text, not a heavy asset bundle.
- **Retention:** rapid rotating poses make immediate replay natural.
- **Originality:** avatars are not just players controlling pieces; avatars are the pieces.
